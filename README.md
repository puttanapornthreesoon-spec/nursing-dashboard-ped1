# Nursing Dashboard PED1

Dashboard สำหรับบันทึกและติดตามการนิเทศทางการพยาบาล กุมารเวชกรรมสาย 1

## การบันทึกข้อมูล

หน้าเว็บบันทึกข้อมูลสองชั้น:

1. ส่งข้อมูลไปยัง Google Sheets ผ่าน Google Apps Script เพื่อให้ใช้ร่วมกันหลายเครื่อง
2. เก็บสำรองใน `localStorage` ของเบราว์เซอร์ทันที เพื่อไม่ให้ข้อมูลที่กรอกหายเมื่ออินเทอร์เน็ตหรือบริการ Google มีปัญหา

ระบบจะไม่แสดงข้อความว่า Google Sheets บันทึกสำเร็จจนกว่าจะได้รับผลตอบกลับสำเร็จจาก backend

## ติดตั้ง Google Sheets backend

1. สร้าง Google Sheet ใหม่ แล้วเปิด **Extensions > Apps Script**
2. คัดลอกไฟล์ `google-apps-script/Code.gs` ไปแทนโค้ดใน Apps Script
3. ตั้งค่า Project Settings > Time zone เป็น `Asia/Bangkok`
4. เลือก **Deploy > New deployment > Web app**
5. ตั้ง **Execute as** เป็นเจ้าของ Sheet และกำหนดผู้ที่เข้าถึงตามนโยบายของหน่วยงาน
6. คัดลอก URL ที่ลงท้ายด้วย `/exec` ไปใส่ในตัวแปร `SCRIPT_URL` ภายใน `index.html`
7. ทดสอบบันทึกหนึ่งรายการ แล้วตรวจว่า Sheet ชื่อ `Records` ถูกสร้างและมีข้อมูลครบ

เมื่อแก้ `Code.gs` ภายหลัง ต้องสร้าง deployment version ใหม่และตรวจว่า `SCRIPT_URL` ยังชี้ไปยัง deployment ที่ต้องการ

## ข้อควรระวังก่อนใช้งานจริง

- หน้า Login เดิมเป็นเพียง client-side demo (`admin` / `admin`) ไม่ใช่ระบบยืนยันตัวตนที่ปลอดภัย
- อย่าบันทึก HN, ชื่อผู้ป่วย หรือข้อมูลสุขภาพที่ระบุตัวบุคคลได้ จนกว่าจะใช้การยืนยันตัวตนและสิทธิ์การเข้าถึงตามนโยบายของโรงพยาบาล
- จำกัดสิทธิ์ Google Sheet และ Apps Script เฉพาะผู้เกี่ยวข้อง และตรวจ audit log ตามนโยบายของหน่วยงาน
